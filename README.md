# Student Marks Analyzer

A beginner-friendly Java project to analyze student marks.

## Features
- Calculate total marks
- Calculate average marks
- Find highest mark
- Find lowest mark
- Count passed students
- Count failed students

## Technologies Used
- Java
- Arrays
- Methods
- Loops

## Sample Output
Total marks: 319
Average marks: 63.8
Highest mark: 90
Lowest mark: 32
Pass students: 4
Fail students: 1

## How to Run
1. Install JDK.
2. Download `demo.java`.
3. Open the terminal in the file's folder.
4. Compile: `javac demo.java`
5. Run: `java demo`
